# Sword Art Online

Sword Art Online is an open-source project that aims to recreate the immersive virtual world of the popular anime and manga series. This project focuses on creating a large starting zone with houses, NPCs, and shops, providing players with a rich and engaging environment to explore and interact with.

## Install

To install Sword Art Online, follow these steps:

1. Clone the repository to your local machine using the following command:
   ```
   git clone https://github.com/yourusername/sword-art-online.git
   ```
2. Navigate to the project directory:
   ```
   cd sword-art-online
   ```
3. Install the required dependencies. Ensure you have Minetest installed and running on your system.

## Use

To use Sword Art Online, follow these steps:

1. Launch Minetest.
2. In the Minetest console, navigate to the project directory:
   ```
   cd path/to/sword-art-online
   ```
3. Run the main Lua script to start the game:
   ```
   minetest --gameid sword_art_online
   ```
4. Explore the large starting zone, interact with NPCs, and engage with the environment.
